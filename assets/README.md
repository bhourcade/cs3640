# This is the README for A5/assets
A5/assets was developed by Carlo Velarde (cvelarde)

# assets
assets is a folder which contains graphs generated by `visualize.py`.

## average_reading_level_by_kind.png
A bar graph showing the average reading level for public, private for-profit and private non-profit universities.

## average_word_length_by_kind.ong
A bar graph showing the average word length for public, private for-profit and private non-profit universities.

## cppa_counts.png
A bar graph showing the number of universities that mention the CCPA or CPRA in their privacy policies.

## dnsmpi_counts.png
A bar graph showing the number of universities that mention have a DNSMPI on their hompage.

## privacy_compliance_by_university_type.png
A bar graph showing the proportion of privacy policies that have DNSMPI links, mention the CPPA or CPRA, mention FERPA, and mention GDPR, for public, private non-profit, and private for-profit universities.

## reading_level_scatter_plot_simple.png
A color coded dot plot displaying the reading level for each university. The color of the points indicates which class of university they belong to.
