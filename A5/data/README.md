# This is the README for A5/data.
A5/data was developed by Benjamin Hourcade (bhourcade), Carlo Velarde (cvelarde), and Logan Martin (logmartin).

This folder contains several useful datasets which will be described below.

# dnsmpi_requirements.xlsx
This file has all the private for-profit universities and determines if each one has a gross annual revenue higher than 25 million. If so, then we consider these universities to be required to have DNSMPI links. This data was manually collected.

## dnsmpi_data.xlsx
This file has every university we investigated in the crawler. It determines if a University is in California and if it is legally required to have a DNSMPI link. This data was manually collected.

# corrected_output.json
`crawler/crawler.py` has a 91% success rate and generates output.py. But, we had to manually add in the data for the remaining 9%. Hence, `corrected_output.json` is a corrected version of what the crawler generates. We used `corrected_output.json` as the final dataset for our analysis. See the README for A5/crawler for more information about the crawler's output.

# data_analysis.csv and data_analysis.xlsx
data_analysis.csv and data_analysis.xlsx are the files generated by `extract_data.py`. See more information about the content of these files in the README of A5/analysis.

# analysis_results.txt
This is the file generated by `analyze_chart_q3.py`. This describes the mean word length, mean reading level, mean sentiment index, proportion of CPPA or CPRA mentions, proprotion of FERPA mentions, proportion of GDPR mentions, and the proprotion of privacy policies that have DNSMPI links for public, private non-profit, and private for-profit universities. See the README for A5/analysis for more information on how this file is generated.
